# Checklist de Calidad — 004 Tipografía Estilo Gilroy

- [ ] La tipografía geométrica estilo Gilroy (`Urbanist`) se aplica en toda la interfaz sin dependencias de fuentes con serifa.
- [ ] Se cargan y están disponibles los estilos principales: 300, 400, 500, 600, 700, 800, 900 y normal/itálica.
- [ ] Los encabezados y nombres de platos lucen nítidos, modernos y con peso audaz (`font-bold` / `font-extrabold`).
- [ ] Los precios y montos se alinean con cifras tabulares perfectamente legibles en dispositivos móviles.
- [ ] La compilación local con `npm run build` finaliza con cero errores.
- [ ] El despliegue en Coolify se actualiza y mantiene el estado `running:healthy`.
